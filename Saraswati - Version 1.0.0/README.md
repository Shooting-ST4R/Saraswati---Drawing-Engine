# Saraswati — Version 1.0.0

First prototype of Saraswati, a native painting app built around a GPU (Vulkan)
brush engine meant to have no perceptible pen lag, even on huge canvases.
Architecture and plan: [DESIGN.md](DESIGN.md).

**Status: in progress** (being built in a Claude Code cloud session). Build and
run instructions will be filled in when the prototype is delivered.
